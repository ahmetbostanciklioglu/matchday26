## 📖 Overview

MatchDay 26 is a static website that serves as the landing page, support hub and privacy policy for the **MatchDay 26** iOS app — a companion for the 2026 tournament hosted across the United States, Mexico and Canada. The site is built as a set of self-contained HTML pages with inline CSS (no build step, no frameworks) and is deployed via GitHub Pages.

It presents the app's feature set, answers common questions, and states the privacy policy — all in a lightweight, responsive layout.

## ✨ Features

- **Landing page** (`index.html`) with a gradient hero, tournament stat highlights (104 matches, 48 nations, 16 stadiums, 3 host countries) and an "App Store — coming soon" call to action.
- **Feature grid** describing the app: live scores & fixtures, groups & knockout bracket, Golden Boot & assists leaderboards, 3D stadiums with live weather, 48 teams & squads, and national anthems & songs.
- **Support page** (`support.html`) with an FAQ and a direct contact link.
- **Privacy Policy page** (`privacy.html`) covering what data is (not) collected, on-device storage, third-party services and user rights.
- **Fully static & dependency-free** — inline CSS, an SVG favicon, responsive layout and smooth-scroll navigation, ready for GitHub Pages (`.nojekyll` included).

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/ahmetbostanciklioglu/matchday26.git
cd matchday26

# Open the site locally — just open the file in a browser
open index.html

# ...or serve it over a local HTTP server
python3 -m http.server 8000
# then visit http://localhost:8000
```

The live site is published with GitHub Pages at **https://ahmetbostanciklioglu.github.io/matchday26/**.

## 📋 Requirements

- Any modern web browser (Chrome, Safari, Firefox, Edge).
- No build tools, package managers or dependencies required — the pages are plain HTML with inline CSS.
- For deployment: GitHub Pages (the repo includes a `.nojekyll` file to serve the files as-is).
